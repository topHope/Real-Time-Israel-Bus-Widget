# Real-Time-Israel-Bus-Widget
an android apk that you can track real time arrivel times of busses/trains in israel and create a homescreen widget that will show the info without even opening the app



## why does this exist
**there is no transit app that have widgets.**  
as a widget person i find that deaply annoying having to open the app.  
i use egg for day-to-day use but i find even that so full of things i dont need for my daily commute. a widget is the perfect solution but it just doesnt exist.  
also they probably track me and **sell my data - a big no no for me!**  


## about this project
ive never used android studio and never used github before lol
my goal is to have the smallest app possible that does what i want and not track me in any way.
my second goal is to learn how to use those tools to make my life better

i use busnearby (hope on/egg) api to get data.
**this app might be unstable/unsafe to use** - if you spoted something in the code, please tell me about it
